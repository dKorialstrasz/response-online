# Evidence для issue #17

Дата проверки: 2026-10-20. Проверка выполнена локально против реального Go backend
и Vite frontend, без mock-протокола. Два игрока работали в отдельных Chromium
browser context; для проверки полной комнаты использовался третий context.

## Воспроизведение

1. Запустить backend: `cd backend && go run ./cmd/server`.
2. Запустить frontend: `pnpm --dir frontend dev`.
3. Установить `NODE_PATH` на каталог, содержащий Playwright, и выполнить
   `node tests/e2e/issue17-browser.cjs`.

Машиночитаемый результат находится в `browser-e2e.json`. Успешный прогон:
Chromium 151.0.7922.34, 13 проверок. Скрипт создаёт настоящие комнаты, выбирает
колоды, подтверждает Приказы и mulligan, отправляет versioned WS-команды и ждёт
серверные персональные проекции.

## Артефакты

- `active-1366x768.png`, `active-640x480.png`, `active-360x640.png`,
  `active-640x360.png` — поле, рука, серверные действия, очередь и журнал на всех
  требуемых viewport.
- `mandatory-choice-owner-640x480.png` — обязательный приватный выбор владельца с
  границами 1..1 и без отказа.
- `mandatory-choice-redacted-360x640.png` — тот же момент для соперника: только
  разрешённое ожидание, без вариантов и скрытых ссылок.
- `optional-choice-360x640.png` — публичный необязательный выбор с явной кнопкой
  «Не активировать».
- `reconnect-restored-1366x768.png` — свежая проекция после реального закрытия и
  восстановления WebSocket.
- `result-rematch-640x480.png` — единственный result overlay и состояние взаимного
  rematch.

Дополнительно прогон проверяет открытие zoom клавишей Enter и закрытие Escape,
открытие справки touch-событием, локальную отмену выбора до отправки, resync при
возврате вкладки, surrender и создание нового матча после двух согласий на
rematch. Скриншоты являются evidence, а полная последовательность утверждений —
в `browser-e2e.json`.

## Границы evidence

Touch проверен эмулированным событием Chromium, а не физическим устройством.
Firefox, Safari и Edge в этом прогоне не запускались. GamePix, iframe и публичное
развёртывание не входят в scope M1.
