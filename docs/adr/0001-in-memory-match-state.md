# ADR-0001: In-memory состояние матчей M1

- Статус: принято
- Дата: 16 октября 2026 года
- Решение: владелец проекта dKorialstrasz
- Связанные требования: OQ-04, FR-28, OPS-04, AC-11
- Связанная задача: [#4](https://github.com/dKorialstrasz/response-online/issues/4)

## Контекст

M1 предназначен для локальной играбельной и тестируемой версии. Для активных комнат и матчей необходимо выбрать между оперативным состоянием процесса и durable recovery. Публичная эксплуатация в M1 не выполняется.

## Решение

Комнаты и активные матчи M1 хранятся только в памяти одного процесса. Перезапуск или crash процесса безвозвратно теряет их состояние. UI сообщает о техническом завершении; матч после crash не восстанавливается. Snapshot store, event log, репликация и иной durable state не входят в M1.

## Последствия

- Реализация проще и быстрее для локального M1.
- RPO активного матча равен всей партии; обещание recovery отсутствует.
- Crash-path и пользовательское сообщение проверяются тестами.
- Потерянному матчу нельзя приписывать игровой исход, которого сервер не зафиксировал до crash.
- Перед публичным развёртыванием решение пересматривается вместе с требованиями к надёжности и эксплуатации.

## Рассмотренная альтернатива

Durable snapshots/event log отклонены для M1 как несогласованное расширение scope. Альтернатива может быть возвращена отдельным ADR для будущего публичного milestone.
