# Тесты

Unit-тесты находятся рядом с Go/TypeScript кодом. Каталог `smoke` содержит
чёрный ящик для локального диагностического API. Будущие contract, integration,
E2E и card-conformance наборы добавляются задачами, которые реализуют
соответствующую функциональность; scaffold не подменяет их пустыми тестами.
